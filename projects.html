RAG Project

Technologies Used: OpenAI API, Node.js, React, MongoDB

Unfortunately this is no longer functional as the API key has lost funding haha, however this was a full stack project.
Using Node.js to create a local server, with Express.js help with the backend framework (Such as implementing RESTful APIs).
React was used for the front end.

The RAG pipeline comes from having the ChatGPT API retrieve a dataset from our MongoDB database, interpret a set of questions, then put its answers back into MongoDB. After which we model the data to compare how well the LLM model does in answer the questions, focusing on its accuracy.

Local LLM with LM Studios (Video Coming Soon!)

Technologies Used: LM Studios, Qwen 3.6/3.8 models, Google Gemma, Tailscale

My favourite personal project! AI is a useful and innovative tool, but subscriptions can add up. I spent $535 on a subscription over the course of 8 months and decided it was time to take the plunge into running my own model, securing my data, and putting my hardware to another use.

Using LM Studio as my llama.cpp wrapper, it made for a quick and easy setup. I was able to get my other devices to connect to my local model running at home, even when I'm away from my local network!

I started this project when LM Link was in very early beta, and connecting to my local network from outside was not as easy as connecting my accounts. Hence I had to configure a VPN to allow my devices from outside the network to connect to my home network without headaches from dealing with my ISP.

This project has taught me a lot, with AI and networking. Now all I have left to do is spend my life savings on more hardware...
